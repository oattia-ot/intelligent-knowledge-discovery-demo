http/https here defaults to https. Switching it also switches every component row's own http/https toggle below — but only while this textbox has a host in it; with the textbox empty, only this row's toggle changes. Use Apply to all to push both this protocol and this host into every IDOL row's own toggle and IP/FQDN textbox (service-specific ports and paths are kept). NiFi canvas is never modified. Then save the host and restart the dev server.
