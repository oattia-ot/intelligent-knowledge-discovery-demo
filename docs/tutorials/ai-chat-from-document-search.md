# Start from a document search

Turn an Answer-panel result into an AI Chat thread without leaving the
demo theme.

## Steps

1. Sign in. The header **Home** pill opens `/home`.
2. Leave the search kind on **Documents** (Home pills under the search
   box; Experts must be On for that row to show).
3. Type a question that Content can answer (a trailing `?` helps the
   Answer panel). Press Enter or the search icon.
4. On `/search`, wait for the **Answer** panel above the hit list.
5. Click **Continue in AI chat** (emphasis pill) to keep this answer
   as turn one.
   Or click **New conversation** to start a fresh thread with the same
   database scope.
6. The app routes to `/chat`. The toolbar shows **Searching
   \<databases\>** and, when continued, a **Continued from answer**
   badge.

## Tips

- Header **AI Chat** always opens `/chat` for a new or last-used scope.
- **Back to results** on the chat toolbar returns to the search URL
  when you came from `/search`.
