# Use and train a Community profile

Community interest profiles are trained by **previewing documents**
while you are signed in. The demo does **not** ship a separate
create-account or “new profile” form. Preview calls train
`ProfileUser` for the current Community user.

## Train

1. Sign in with a Community user that is allowed to have a profile.
2. Run a [document search](./document-query-guidance.md).
3. Open (preview) several hits that represent your interests.
4. Repeat on another topic so the term list is not a single cluster.

## Review

1. Header **Settings**.
2. Open the profiles / **My profile** view (settings profiles page).
3. Expand a profile row to see stored terms.
4. Filter the list if you have several profile ids.

## Use

- [Experts search](./experts-on-and-search.md) ranks people whose
  terms overlap the query or overlap yours.
- Recommendations (when On) can use the same Community signal.

## What not to expect

- No “Create profile” button.
- Chat follow-ups do not by themselves write profile terms.
- Deleting a profile from Settings removes terms; it does not delete
  the Community login.
