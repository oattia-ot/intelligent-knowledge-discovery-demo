# New conversation and scope

Reset the thread and see which IDOL databases the assistant may search.

## Steps

1. Open **AI Chat** from the header, or continue from an Answer panel.
2. Read the toolbar line **Searching \<scope\>**.
   Scope is the database list from the last search (or the default
   configured databases when you did not search first).
3. Click **New conversation** (pill on the right of the toolbar).
   The thread clears. Scope stays unless you started from a different
   search.
4. Type a first question and click **Send** (navy emphasis pill) or
   press Enter.
5. To change scope, go **Home**, search again with different sources /
   databases selected on `/search`, then **Continue in AI chat** or
   header **AI Chat**.

## Badges

| Badge | Meaning |
|-------|---------|
| Continued from answer | First assistant turn is the Answer panel text |
| Sources only | Follow-ups are locked to the cited documents |
