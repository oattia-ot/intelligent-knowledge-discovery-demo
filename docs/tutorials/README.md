# Tutorials

Step-by-step operator guides for the Intelligent Knowledge Discovery Demo.
Open the search UI at **http://localhost:4200**, sign in, then follow a topic
below. Header and in-page actions use the same pill control
(`.hdr-btn` in the header, `.op-btn` everywhere else).

Also listed from the package [README.md](../../README.md#tutorials).
